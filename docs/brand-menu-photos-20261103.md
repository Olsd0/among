# 브랜드 메뉴 사진 (2026-11-03)

핫딜에 공식 행사 이미지가 없을 때 같은 브랜드의 관련 상품 사진으로 쓰는 공식 메뉴 사진이다. 각 브랜드 공식 메뉴 페이지에서 상품명과 사진을 대조했고, 사진 주소가 실제로 열리는지 확인했다. 파일은 저장하지 않고 공식 주소만 둔다. 화면에는 '관련 상품 이미지'(공지 글에 상품명이 나온 경우) 또는 '대표 메뉴 이미지'(브랜드 첫 번째 사진)로 표시해 행사 이미지와 구분한다.

확인 방법: 오전에는 대표 PC의 데스크톱 앱 브라우저, 오후(푸라닭·커피빈·설빙)에는 GitHub 실행기의 사진 점검(`collect.yml` mode `images`, only=`menu=메뉴 페이지 주소들`)으로 상품명·사진·크기를 대조했다.
