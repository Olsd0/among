# 온라인 특가 시험 운영

기본 화면은 프랜차이즈 쿠폰 비교다. 온라인 특가는 마지막 메뉴에서 선택한 경우에만 별도 화면으로 열린다. 기존 쿠폰 데이터, 수집기, Apps Script, 추천 순위, 통신사·결제수단 필터에는 온라인 상품을 넣지 않는다.

## 이번 버전의 실제 범위

- 메뉴: 전체 혜택 → 브랜드별 → 구독 브랜드 → 온라인 특가.
- 직접 주소: `?view=onlineDeals`.
- 쿠팡 골드박스 공식 일반 링크와 와우회원 전용 조건을 안내한다.
- 현재 상품 JSON은 `items: []`다. 확인하지 않은 상품명·가격·사진을 실제 상품처럼 게시하지 않는다.
- 파트너스 계정, 제휴 링크, API 키, 자동 상품 수집은 아직 연결하지 않았다. 현재 일반 링크에는 수수료 고지를 표시하지 않는다.
- 기존 앱 쿠폰 데이터와 관리자 화면은 보존한다. 기존 `?view=appCoupons`·`?ac=...` 주소도 계속 작동한다.

골드박스가 와우회원 전용 할인 코너라는 설명은 [쿠팡 공식 안내](https://news.coupang.com/archives/31239/)와 [와우 멤버십](https://loyalty.coupang.com/loyalty/sign-up/home)에서 확인했다. 공식 이동 주소는 `https://www.coupang.com/np/goldbox`다. 자동 조회 환경에서는 403 응답이 발생했으므로 상품 내용이나 현재 가격을 이 페이지에서 수집했다고 표시하지 않는다.

## 끄기 / 복원

`web/config.js`에서 `onlineDeals.enabled`를 `false`로 바꿔 배포하면 된다. 온라인 특가 메뉴가 사라지고 원래 앱 전용 쿠폰 메뉴가 복원된다. 기능이 꺼진 상태의 직접 주소는 기본 쿠폰 화면을 연다. 상품 JSON이나 기존 쿠폰·구독 데이터는 삭제하지 않는다.

전체 변경을 되돌릴 때는 이 기능의 병합 커밋을 revert한다. 프런트엔드만 바꾸므로 Apps Script 재배포나 시트 마이그레이션은 필요하지 않다.

## 분리 방식

- `web/online-deals.js`, `online-deals.css`, `online-deals.json`은 해당 탭을 처음 열 때 요청한다. 서비스 워커의 사전 캐시에도 넣지 않는다.
- 기본 쿠폰 화면에서 추가 광고 스크립트·위젯·쿠팡 요청이 발생하지 않는다. 일반 링크는 이용자가 눌렀을 때 새 탭으로 열린다.
- 같은 출처의 JSON만 읽는다. 외부 리디렉션과 인증정보 전송을 허용하지 않으며 상품 응답은 서비스 워커·로컬 저장소에 저장하지 않는다.
- 로딩 실패, 재시도, 상품 만료는 이 화면 안에서 처리한다.
- 같은 쿠폰 화면으로 돌아오면 검색어·필터·정렬·펼친 카드·스크롤 위치를 유지한다. 다른 탐색 메뉴를 고르면 해당 메뉴의 기존 동작을 따른다.
- CSP 허용 도메인을 넓히지 않고 기존 테마와 스타일 변수를 사용한다.

## 상품을 연결할 때

공식 제공 방식과 재게시 허용 범위를 확인한 실제 데이터만 사용한다. API 이용 가능 여부와 데이터 보관·이미지 사용 허용은 별도로 확인해야 한다. 프런트엔드 설정이나 공개 JSON에 API 비밀키를 넣지 않는다. [쿠팡 파트너스 약관](https://partners.coupang.com/#help/terms) 및 [공식 가이드](https://partners.coupangcdn.com/partners-guide/partners-guide-20260917111657.pdf)를 기준으로 연결한다.

`web/online-deals.json`의 각 `items` 항목:

| 필드 | 의미 |
| --- | --- |
| `id` | 중복되지 않는 항목 ID |
| `title` | 직접 확인한 상품명 |
| `unit` | 용량·수량·옵션 |
| `price` | 확인 당시의 양의 정수 가격. `3000원` 형식으로 표시 |
| `conditions` | 회원·쿠폰·결제·배송 등 적용 조건 문자열 배열. 조건 없음도 확인 후 명시 |
| `url` | 공식 이동 주소 또는 본인 파트너스에서 발급받은 링크 |
| `sourceUrl` | 사실을 확인한 공식 상품·행사 주소 |
| `checkedAt` | 확인 시각. 시간대가 포함된 ISO 8601 |
| `expiresAt` | 실제로 확인한 행사 종료 또는 운영자가 설정한 재확인 마감 시각. 시간대 포함 |
| `affiliate` | 제휴 링크이면 `true` |
| `imageUrl` | 선택. 사용 권한과 상품 일치를 확인한 Coupang CDN 상품 사진 |
| `category` | 선택. `food` 또는 `household` |

화면은 필수 정보가 없거나 기간이 지난 항목을 제외하고 최대 10개까지 표시한다. 확인 시각부터 24시간이 지나면 숨기는 것은 오래된 가격을 줄이기 위한 **운영 기준**이며, 가격 유효성이나 데이터 이용 권한을 보장하는 기준이 아니다. 할인율이나 최저가 표현을 임의로 만들지 않는다.

제휴 링크가 있는 경우 화면 시작 부분에 경제적 이해관계 문구를 표시하고, 해당 상품에 `제휴광고` 표시 및 `rel="sponsored noopener noreferrer"`를 붙인다. 실제 수익 연동 전에는 가입 상태·활동 매체 등록·사용 범위를 확인한다.

## 검증

`collector`에서 `npm test`를 실행한다. 새 테스트는 기본 화면의 지연 로딩, 탐색 상태 복원, 오류 격리, 기능 끄기, 기존 앱 쿠폰 공유 링크, 제휴 표시, 모바일 너비, URL·HTML·기간 검증을 다룬다. 테스트 상품은 테스트 코드에만 있으며 공개 JSON에는 포함하지 않는다.

`AMONG_QA_SCREENSHOT`을 지정하면 기존 모바일 QA 아티팩트와 함께 온라인 특가의 일반·상품·어두운 테마 화면을 저장한다.
