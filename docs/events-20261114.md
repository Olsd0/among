## 운영 방식

- verified-events.js는 수동 확인 보완본이다. 확인시각을 렌더링/매일 수집시각으로 바꾸지 않는다. 기존 최신 수집 결과와 중지 상태를 보존하고 종료된 회차를 제거한다. 공개 API가 누락하는 관리자 숨김 기록은 프런트 보완본에서 알 수 없으므로, 수동 보완 행사의 영구 중지는 해당 항목도 제거해야 한다.
- 자동 수집기는 활성 npay-cafe를 공식 F&B 목록 및 상세 최대8개로 보정한다. 중지/사용자 지정 출처와 robots 정책을 유지한다. 이번 실행에서 확인한 기간 한정 결제·증정 쿠폰은 공지로 함께 연결한다.
- 수동 보완본을 collector ingest에 재전송하지 않는다. 현행 Apps Script가 ingest 시각을 확인시각으로 저장하므로, 수동 내용을 매일 재검증한 것처럼 보이게 하지 않기 위함이다.
- 핫딜의 마감임박→공지최신→상시 순서, 브랜드당2개/전체8개 및 해피포인트1+1/50% 기준은 유지한다. 개별 브랜드에서 해당 공지를 확인할 수 있다.
- 포인트 적립은 결제가격을 낮추지 않는다. 적립한도는 P로 표시한다. 공지에는 해당 행사의 공식 포스터를 우선 사용한다. 별도 포스터에 접근할 수 없는 Npay 5건은 공식 상세 또는 목록의 실제 행사 부분을 캡처하고 화면에서 캡처임을 표시한다. 임의 문구를 그려 만든 이미지는 사용하지 않는다.
- 원문 버튼은 Npay 목록과 행사 상세를 구분한다.

## 검증

전용 테스트는 별도 행사, 중복, 만료 경계, 같은 ID의 다음 회차, 최신 확인 보존, 적립가격과 한도를 확인한다. 브라우저 fixture는 실제 수동 행사 모듈을 중립화하며 별도 events-browser.test.js에서 실제 보완본 통합을 확인한다. 로컬 자동 브라우저는 OS 네트워크 제한으로 localhost 연결이 차단되어, 모바일 실데이터 화면 확인은 인앱 브라우저로 수행한다.

15개 공지에 공식 이미지 또는 공식 페이지 캡처를 연결했다. 16개 WebP 파일은 원본을 최적화한 것이며, 생성 이미지는 없다. 출처와 원본 주소는 `event-artwork-20261114.json`에 기록했다. 캡처에는 포스터와 구분되는 라벨을 붙이고, 카드에서 자르지 않는다. 던킨 증정 포스터는 카드용 상단과 상세 전체 이미지를 구분한다.
