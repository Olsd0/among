기간은 KST 종료일 포함. Npay 목록의 오늘 종료·D-1 표시는 11/14 직접 확인했고, 미확인 시작일·적립한도는 생성하지 않았다. 행사 조건은 verified-events.js의 각 항목에 기록했다. 재고 소진형 브로마이드, 혜택 수치 미확인 Sweet Week, 종료 행사와 추첨 경품은 추가하지 않았다.

## 운영 방식

- verified-events.js는 수동 확인 보완본이다. 확인시각을 렌더링/매일 수집시각으로 바꾸지 않는다. 기존 최신 수집 결과와 중지 상태를 보존하고 종료된 회차를 제거한다. 공개 API가 누락하는 관리자 숨김 기록은 프런트 보완본에서 알 수 없으므로, 수동 보완 행사의 영구 중지는 해당 항목도 제거해야 한다.
- 자동 수집기는 활성 npay-cafe를 공식 F&B 목록 및 상세 최대8개로 보정한다. 중지/사용자 지정 출처와 robots 정책을 유지한다. 이번 실행에서 확인한 기간 한정 결제·증정 쿠폰은 공지로 함께 연결한다.
- 수동 보완본을 collector ingest에 재전송하지 않는다. 현행 Apps Script가 ingest 시각을 확인시각으로 저장하므로, 수동 내용을 매일 재검증한 것처럼 보이게 하지 않기 위함이다.
- 핫딜의 마감임박→공지최신→상시 순서, 브랜드당2개/전체8개 및 해피포인트1+1/50% 기준은 유지한다. 개별 브랜드에서 해당 공지를 확인할 수 있다.
- 포인트 적립은 결제가격을 낮추지 않는다. 적립한도는 P로 표시한다. 공지에는 해당 행사의 공식 포스터를 우선 사용한다. 공식 포스터를 먼저 찾고, 확보하지 못하면 공식 상품·매장 관련 사진을 사용한다. 페이지 캡처는 두 종류의 이미지를 모두 확보하지 못한 경우에만 사용한다. 현재 Npay 4건의 캡처는 공식 관련 사진으로 교체했다. 임의 문구를 그려 만든 이미지는 사용하지 않는다.
- 원문 버튼은 Npay 목록과 행사 상세를 구분한다.

## 검증

전용 테스트는 별도 행사, 중복, 만료 경계, 같은 ID의 다음 회차, 최신 확인 보존, 적립가격과 한도를 확인한다. 브라우저 fixture는 실제 수동 행사 모듈을 중립화하며 별도 events-browser.test.js에서 실제 보완본 통합을 확인한다. 로컬 자동 브라우저는 OS 네트워크 제한으로 localhost 연결이 차단되어, 모바일 실데이터 화면 확인은 인앱 브라우저로 수행한다.

## 공식 행사 이미지 보완

15개 공지에 공식 행사 이미지 또는 공식 관련 사진을 연결했다. 현재 연결된 16개 WebP 파일(공식 행사 이미지 11건·공식 캠페인 포스터 1건·일반 공식 관련 사진 3건)은 원본을 최적화한 것이며, 생성 이미지는 없다. 출처와 원본 주소는 `event-artwork-20261114.json`에 기록했다. 공식 상품·매장 사진에는 “공식 관련 이미지”를 표시해 행사 포스터와 구분한다. 던킨 증정 포스터는 카드용 상단과 상세 전체 이미지를 구분한다.

이미지 확인 중 종료일이 누락된 파파이스 2건(11/8, 11/11), 빽다방 말차 1건(1/8 종료)과 해당 말차 쿠폰의 날짜를 보정했다. 파파스데이는 게시 시작일 11/9가 아니라 실제 행사일 11/18 하루로 바로잡았다. 수정은 확인한 ID·최초 수집시각·제목·출처가 일치할 때만 적용하고, 새 회차나 명시된 다른 날짜는 보존한다.
설빙 공식 홈페이지의 Instagram 연동 피드에서 11/12~15 공식 포스터를 확인해 캡처를 교체했다. 기간 내 1인 최대 30000P 적립 조건도 반영했다.

## 이미지 우선순위 보완

공식 행사 포스터 → 공식 행사 관련 상품·매장 사진 → 실제 공식 페이지 캡처 순으로 선택한다. 네이버페이 목록에서 멈추지 않고 행사 상세와 브랜드 공식 출처를 확인한다. 포스터를 확인하지 못한 경우 다른 행사의 포스터를 대체 사용하지 않는다. 이번에 쉐이크쉑·파스쿠찌·HANS·가평휴게소의 캡처 4건을 공식 관련 사진으로 교체했다. 설빙 포스터의 문구도 다시 확대 대조해, 원문에 없는 “1회” 제한을 제거하고 “기간 내 1인 최대 30000P”로 바로잡았다.

## 기사 이미지 추가 검증

파스쿠찌는 삼립이 한국경제에 배포한 2026-11-02 보도자료(https://www.hankyung.com/article/202611029284P)에 11/11~15 Npay 1만원 이상 40% 행사와 함께 실린 공식 크리스마스 캠페인 포스터로 교체했다. 기존 일반 커피 사진보다 해당 프로모션과의 관계가 확인되는 이미지다. Npay 결제 혜택 전용 포스터와 구분해 “공식 캠페인 이미지”로 표시한다. 보도자료에서 시작일 11/11도 확인했다.

이미지 선택 기준은 해당 행사 공식 포스터 → 같은 프로모션과 함께 공개된 공식 캠페인/브랜드 제공 보도 이미지 → 최후의 수단으로 실제 공지 캡처다. 일반 상품·매장 사진은 행사 이미지 확보 완료로 취급하지 않는다. HANS·가평휴게소·쉐이크쉑의 일반 관련 사진은 미해결 항목으로 남는다. 아시아투데이 카드뉴스는 행사 내용은 일치하지만 AI 생성 사진이어서 채택하지 않았다.

기존 매일 수집은 유지된다. 기사 검색 모듈은 기간 검증용이며, 이 변경이 기사 이미지 자동 검색·게시를 구현한 것은 아니다. 사용자에게 매일 이미지 업로드를 요구하는 운영 방식은 채택하지 않는다.

### 매일 공지 이미지 보완 연결
- 기존 collect 예약 실행에서 기간·쿠폰 연결 후, 이미지 없는 유효 공지와 일반 공식 관련 사진을 최대 8건 보완한다. 공식 행사 포스터는 보존한다.
- 우선 확보한 공식 이미지 → 공개 공식 뉴스룸/기업 보도자료 피드 → 연결된 경우 뉴스 검색 API의 브랜드 제공 사진. 현재 API 키 없이도 RSS 3곳에서 작동한다.
- 기본 RSS: https://www.smdnewsroom.co.kr/feed/ · https://api.newswire.co.kr/rss/industry/916 · https://api.newswire.co.kr/rss/industry/912
- 기사 제목의 브랜드·발행일(45일 이내)·사진 출처를 대조하고 다른 혜택/기간·AI 명시 이미지·로고를 제외한다. 확인 안 된 경우 기존 이미지를 유지하며 다음 수집에서 다시 찾는다.
- 한 실행 총 60초/공지 8건/공지당 기사 2개/요청 48회/파일 2MB 제한. 원문 robots·HTTPS 인증·리다이렉트·공개 IP를 검사한다.
- 기존 Sheets image_url 열에 HTTP로 전송되지 않는 fragment로 종류·기사 출처·확인일을 함께 보관. 공개 API에서 디코딩 후 이미지 URL과 출처를 분리하므로 backend 재배포 불필요. 기간 근거와 공식 행사 링크는 변경하지 않는다.
- 같은 id/브랜드/시작일/종료일의 이전 기사 이미지를 확인일 갱신 없이 재사용한다. 모의 수집 테스트는 외부 네트워크를 호출하지 않는다. ARTWORK_LOOKUP=0으로 중지 가능.
- 실검증: 게시 중인 파리바게뜨 홀리데이 공지의 이미지 없는 사본으로 읽기 전용 실행. RSS 3곳, 기사 1건, 요청 7회로 브랜드 사진 확보. 검색 API 미연결 상태에서 성공; 운영 데이터의 더 좋은 공식 포스터는 유지.
- 화면/저장 회귀: metadata 왕복, 기존 Apps Script ingest→공개 API, 브라우저 출처/라벨, 수집기 기간 검증→이미지 보완→ingest 순서.
