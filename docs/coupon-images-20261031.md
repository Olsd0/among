# 쿠폰 포스터·대표 메뉴 이미지 (2026-10-31)

사용자 요청에 따라 정확한 단품 사진 외에 같은 행사 포스터와 브랜드 대표 사진을 쿠폰 목록·핫딜·펼친 상세에 표시한다. 할인 정보와 확인 시각은 바꾸지 않는다.

- 반올림 ‘제휴 메뉴’는 공식 명일방주 행사 상세 URL과 종료일(2026-11-08)을 대조해 기존 공식 썸네일을 사용한다. 상세에서 원본 포스터를 열 수 있다. 다른 통신사·전 메뉴 할인에는 이 포스터를 붙이지 않는다.
- 배스킨라빈스 파우치·파인트, 피자헛 클리커, 파파존스 아메리칸 콤보, KFC 닭껍질 행사도 같은 상세 URL과 메뉴가 맞을 때 기존 공지 이미지를 연결한다.
- 전 메뉴·복수 메뉴 쿠폰에는 같은 브랜드의 공식 대표 사진과 ‘대표 메뉴’ 표시를 사용한다. 특정 단품·크기·수량·세트에 대표 사진을 정확한 상품 사진처럼 연결하지 않는다.
- 쉐이크쉑은 국내 운영사 상미당홀딩스 공식 브랜드 소개의 여러 버거가 나온 사진을 사용한다. 한국 브랜드 홈페이지는 확인 당시 robots.txt가 HTTP 503을 반환해 이용하지 않았다.
- 새로 보관한 대표 사진 4장은 원본 바이트 그대로이며 SHA-256 앞 12자리를 파일명에 넣었다. 공식 URL과 확인일은 코드에 보존한다. 기존 맥도날드·파리바게뜨 메뉴 사진은 확인한 원본 URL을 재사용한다.
